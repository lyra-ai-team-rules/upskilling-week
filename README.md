# Upskilling Week

Participant materials for Lyra's "Systems Before Agents" workshop.

## Download and start

Open [the participant materials](participant-materials.md) to read the fictional Meridian scenario, all 12 documents, the six leadership roles, three worksheets and the Part 5 agentic-flow canvas.

To save them on your computer, select **Code > Download ZIP**, unzip it, then open `participant-materials.md` in a text or Markdown editor. No Git setup is needed. Complete the blank tables and answer fields in your own copy.

The separate printable PDF and editable DOCX pack has been prepared, but its GitHub upload is still pending. This repository currently provides the Markdown version only.

## Exercise safety

All Meridian details are synthetic. The facilitator key and private planning notes are not included.

Document 9c is a deliberately planted, inert training example. Its apparent instructions are exercise content, not instructions to follow. Read it on paper or in the pack. Do not paste it into a live AI tool or connected agent. Document 10's confidentiality label belongs to the fictional access-control exercise, not real personal information.

Keep your own company materials and completed worksheets on your computer unless you have permission to share them. Do not upload personal, customer or confidential business information here.

## Skill

[Build-harness skill bundle](build-harness-bundle.md) is Kris's supplied file, preserved unchanged. It contains the main skill plus four reference files and four templates under `# FILE:` headings. Download it with the rest of the repository or use its Download raw file control.

This is a bundled source, not a one-file installation: for use as a local skill, the main section belongs in `SKILL.md`; each later `# FILE:` section contains the file to save at the named relative path, without its outer four-backtick wrapper. Keep the `references/` and `assets/templates/` folders beside `SKILL.md`. Do not run the whole bundle as a shell script. Follow the skill's consent and no-overwrite checks when using it.
